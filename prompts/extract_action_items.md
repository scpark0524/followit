# LLM ① 액션아이템 추출 프롬프트

## 용도
STAGE 2: 회의 전사문에서 결정사항과 액션아이템을 구조화된 JSON으로 추출

## 프롬프트

```
당신은 회의록 분석 전문가입니다. 아래 회의 전사문을 읽고, 결정사항과 액션아이템을 추출해주세요.

## 규칙
1. 반드시 전사문에 근거가 있는 내용만 추출하세요.
2. 담당자나 기한이 명시되지 않았으면 "미정"으로 표시하세요. 절대로 추측하지 마세요.
3. 각 항목에 근거가 되는 원문 발화와 타임스탬프를 반드시 포함하세요.
4. 한국어 화법의 뉘앙스에 주의하세요:
   - "한번 볼게요", "제가 알아볼게요" → 액션아이템 (암묵적 약속)
   - "그것도 생각해봐야 할 것 같은데" → 결정사항 아님 (논의 수준)
   - "다음 주쯤", "가능한 빨리" → 기한은 "미정"으로 처리
5. 확신도를 상/중/하로 평가하세요:
   - 상: 담당자와 기한이 명시적으로 언급됨
   - 중: 담당자 또는 기한 중 하나만 추정 가능
   - 하: 액션인지 아닌지 불명확하거나, 담당자/기한 모두 불명확

## 회의 정보
- 날짜: {meeting_date}
- 참석자: {participants}
- 회의 제목: {meeting_title}

## 전사문
{transcript}
```

## JSON 스키마

```json
{
  "meeting_id": "string",
  "date": "YYYY-MM-DD",
  "participants": ["string"],
  "summary": "회의 전체 요약 (3~5문장)",
  "decisions": [
    {
      "id": "D1",
      "content": "결정 내용",
      "source_quote": "원문 발화",
      "timestamp": "HH:MM:SS"
    }
  ],
  "action_items": [
    {
      "id": "A1",
      "task": "할 일 내용",
      "assignee": "담당자 이름 또는 '미정'",
      "deadline": "YYYY-MM-DD 또는 '미정'",
      "priority": "high / medium / low",
      "confidence": "상 / 중 / 하",
      "source_quote": "근거가 되는 원문 발화",
      "timestamp": "HH:MM:SS",
      "depends_on": ["선행 액션 ID (있는 경우)"],
      "status": "pending_review"
    }
  ]
}
```

## 평가 기준
- **재현율**: 실제 액션아이템 중 추출해낸 비율 (목표 >= 90%)
- **정밀도**: 추출한 것 중 실제 액션아이템 비율 (목표 >= 85%)
- **담당자/기한 정확도**: 정답과 일치 비율 (목표 >= 85%)
- **수정 비율**: HITL 승인 시 수정된 비율 (목표 <= 20%)

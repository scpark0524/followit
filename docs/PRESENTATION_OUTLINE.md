## S2. 문제 정의 (1분)
### "회의록 AI는 넘쳐나는데, 왜 회의는 여전히 회의에서 끝나나?"

**근본 원인 3가지**:
1. **주인 불명확** — "그거 누가 하기로 했죠?" (책임 분산)
2. **기한 모호** — "다음 주쯤", "가능한 빨리" (구체성 부족)
3. **팔로업 부재** — 다음 회의에서 확인 없이 새 안건으로 (실행 격차)

**핵심 메시지**: PM이 회의록 정리, 태스크 등록, 진행 확인을 수작업으로 하고 있음. 이 일이 누락되는 순간 결정사항은 사라진다.

## S3. 시장 분석 + 포지셔닝 (30초)
### "기존 AI 회의 도구는 '등록'에서 멈춘다"

| | 기존 도구 | Action Keeper |
|---|---|---|
| 녹음→추출→등록 | O | O (기존 템플릿 활용) |
| R&R 추천 + 타임라인 | X | **O** |
| 팔로업 대화 + 답변 해석 | X | **O** |
| 지연 감지 + 일정 재조정 | X | **O** |
| 다음 회의 안건 자동 | X | **O** |

> "추출·등록은 기존 템플릿 활용. 우리는 **확인·추적·완결**에 집중."

## S4. 솔루션 - 5단계 워크플로 (1분 30초)
### "녹음부터 다음 회의 안건까지, 끝나지 않는 고리"

```
STAGE 1. 기록: 녹음 → STT (화자 구분)
STAGE 2. 추출: LLM → 액션/담당자/기한/근거 + 확신도
STAGE 3. R&R + 타임라인: 미정 업무 배정 제안 + 선후관계 역산 → HITL 승인 → 등록
STAGE 4. 추적: D-2 팔로업 DM → 답변 해석 → 지연 시 파급 관리
STAGE 5. 순환: 미완료/막힌 일 → 다음 회의 안건 자동 생성
```

**AI가 꼭 필요한 3가지**:
- "그건 제가 한번 볼게요" → 액션아이템인지 판단 (키워드 규칙 불가)
- "중간발표 전까지는 돼야죠" → 실제 날짜 변환
- "자료가 아직 안 와서요" → 막힘(blocker) 분류

**n8n 어필 포인트**: Wait 노드(사람 응답 대기) + Switch 분기 = "사람과 주고받는 워크플로"

## S6. 성공 기준 (30초)
### "3층으로 측정한다: 품질 / 성과 / 효율"

| 층위 | 핵심 지표 | 목표 |
|---|---|---|
| 품질 | 추출 재현율/정밀도 | >= 85~90% |
| **성과** | **기한 내 완료율** | **기준값 대비 +30%p** |
| 효율 | 회의 후 정리 시간 | 30분 → 5분 |

- 팀 프로젝트 회의 자체가 실험장 → 학기 내내 데이터 축적
- 교란 변수(학기말 압박) 인정 + 시기 무관 지표 병행

## S7. 수행 계획 (30초)
### "이 팀 자체가 실험장이다"

| 기간 | 마일스톤 |
|---|---|
| 10/24~11초 | STAGE 1~2 구현, 최소 기능 버전 |

| 12월 | 데이터 축적 + 결과 분석 → 기말 라이브 데모 |

> 핵심: 11월부터 팀 회의에 실적용 → **5~6주치 실데이터** 확보

## 질의응답 대비 Top 3

**Q: "클로바노트/Circleback이랑 뭐가 달라요?"**
→ "Circleback은 일을 등록할 때까지 책임지고, 우리는 일이 끝날 때까지 책임집니다."
→ 비교 표로 STAGE 4~5 부분이 빈 영역임을 보여줌

**Q: "AI가 담당자를 틀리게 정하면요?"**
→ 근거 발화 인용 필수 + 확신도 표시 + HITL 승인 단계 + 수정 비율 측정
→ 근거가 없으면 "미정"으로 처리 (hallucination 방지)

**Q: "이행률이 오른 게 AI 덕분인지 어떻게 알죠?"**
→ 교란 변수를 먼저 인정 (학기 후반 마감 압박)
→ 시기와 무관한 지표로 보완: "사람이 놓쳤는데 AI가 잡아낸 액션 수"
→ 이 한계를 스스로 언급하면 오히려 신뢰도 상승

## S2. 문제 ① (1분)
### "회의는 끝났는데, 일은 시작되지 않는다"

- **54%** — 회의 후 다음 할 일·담당자를 모른 채 자리를 뜨는 직장인 비율 (Atlassian 2024)
- 근본 원인 3가지:
  1. **주인 불명확** — "그거 누가 하기로 했죠?" (책임 분산)
  2. **기한 모호** — "다음 주쯤", "가능한 빨리" (구체성 부족)
  3. **팔로업 부재** — 다음 회의에서 확인 없이 새 안건으로 (실행 격차)
- 핵심 메시지: PM이 회의록 정리 → 태스크 등록 → 진행 확인을 수작업으로. 누락되는 순간 결정사항은 사라진다.

## S4. 솔루션 — 5단계 워크플로 (1분 20초)
### "회의를 기억하고, 연결하고, 끝까지 챙긴다"

```
1. 연동      : 녹음앱 연결 (MCP) · 전사문 가져오기
2. 회의 연결  : 이전 회의와 묶기 · 기존 액션 이어 추적
3. 액션·R&R  : 액션 추출 · R&R 추천 · 모호하면 HITL 확인
4. 타임라인   : 기한·선행관계 역산 · 변경사항 반영
5. 후속관리   : 진행 확인 · 답변 해석 · 미완료 → 다음 안건
↻ 다음 회의 녹음 → 이전 회의·액션과 자동 연결 (closed loop)
```

**AI가 꼭 필요한 3가지**:
- "그건 제가 한번 볼게요" → 액션아이템 판단 (한국어 화법 맥락)
- "중간발표 전까지는 돼야죠" → 암묵적 기한을 실제 날짜로 변환
- "자료가 아직 안 와서요" → 막힘(blocker) 상태 자동 분류

**n8n 어필 포인트**: Wait 노드(사람 응답 대기) + Switch 분기 = "사람과 주고받는 워크플로"

## S5. 성공 기준 (50초)
### "회의 이후, 사람이 챙기는 부담이 줄었는가"

두 단계:
- **① 구현 성공** — 회의 가져오기 → 이전 회의 연결 → 액션 확인 → 후속관리가 실제로 작동하는가
- **② 사용 성공** — 쓰면서 오류·누락이 줄고, 사람이 직접 챙기는 시간과 부담이 줄었는가

3축 측정:
| 축 | 측정 방법 |
|---|---|
| 추적 정확성 | 액션 누락·중복 건수, 담당자·기한 수정 건수 |
| 후속관리 신뢰성 | 예정된 F/U 정상 처리율, 누락·불필요 알림 건수 |
| 실제 사용 가치 | 기한 내 완료율 변화, 유용성·지속 사용 의향 |

- 목표치는 초기 2주 실사용 결과를 보고 확정 (11/21)
- 교란 변수(학기말 압박) 인정 + "AI만 잡아낸 액션 수" 등 시기 무관 지표 병행

## 질의응답 대비 Top 4

**Q: "클로바노트/Circleback이랑 뭐가 달라요?"**
→ "Circleback은 일을 등록할 때까지 책임지고, 우리는 일이 끝날 때까지 책임집니다."
→ 비교 표에서 회의 연결 + 추적 영역이 빈 영역임을 보여줌

**Q: "녹음앱 MCP/API 연동이 실제로 되나요?"**
→ 공개 API가 없거나 제한적인 앱이 많음을 인정
→ MVP는 연동 가능한 앱 1개 또는 내보내기 파일 업로드 폴백으로 시작, MCP는 아키텍처 방향
→ 핵심 가치(연결·추적·완결)는 전사문 입수 경로와 무관하게 동일 작동

**Q: "AI가 담당자를 틀리게 정하면요?"**
→ 근거 발화 인용 필수 + 확신도 표시 + HITL 확인 단계 + 수정 건수 측정
→ 근거가 없으면 "미정"으로 처리 (hallucination 방지)

**Q: "이행률이 오른 게 AI 덕분인지 어떻게 알죠?"**
→ 교란 변수를 먼저 인정 (학기 후반 마감 압박)
→ 시기와 무관한 지표로 보완: "사람이 놓쳤는데 AI가 잡아낸 액션 수", 알림 누락·중복 건수
→ 목표치를 초기 실사용 후 확정하는 것도 같은 맥락 — 이 한계를 스스로 언급하면 오히려 신뢰도 상승
